# Analisis Komparatif Platform Pengembangan Aplikasi

Tabel berikut menyajikan perbandingan antara platform Web, Desktop, dan Mobile berdasarkan berbagai aspek teknis dan operasional.

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| Bahasa Utama | JavaScript, TypeScript, PHP | C++, C#, Java, Python, Swift | Kotlin , Swift , Dart , JavaScript/TypeScript (React Native) |
| Arsitektur | Client-Server, Micro-frontends, Single Page Application (SPA), Progressive Web App (PWA) | Monolithic (Standalone), Client-Server, Model-View-Controller (MVC), Component-Based | Model-View-ViewModel (MVVM), Model-View-Controller (MVC), Clean Architecture |
| Cara Distribusi | Web Hosting, Cloud Platform, Content Delivery Network (CDN) | Executable Installer (.exe, .msi, .dmg, .AppImage), App Store (Microsoft Store, Mac App Store) | App Store (Google Play Store, Apple App Store, Huawei AppGallery) |
| Keunggulan | Mudah diakses tanpa instalasi khusus, tampilan cross-platform secara instan melalui media query, pembaruan aplikasi terjadi secara langsung (real-time update) di sisi server. | Akses penuh ke hardware lokal (GPU, RAM, storage), performa tinggi, dapat berjalan sepenuhnya secara offline. | Memanfaatkan fitur hardware spesifik (kamera, GPS, sensor, push notification), sangat portabel, UX yang lebih optimal untuk layar sentuh. |
| Keterbatasan | Akses ke perangkat keras lokal terbatas, sangat bergantung pada koneksi internet dan performa browser juga tergantung terhadap server. | Memerlukan proses instalasi, ruang penyimpanan lebih besar, pembaruan aplikasi harus diunduh manual oleh pengguna. | Ukuran memori dan daya baterai terbatas, ketergantungan pada kebijakan serta proses review app store. |
| Contoh Aplikasi | Figma (Web), Canva (Web), MDN Web Docs | Visual Studio Code, Adobe App, Capcut PC | WhatsApp Mobile, Instagram, Grab, Game Mobile |
